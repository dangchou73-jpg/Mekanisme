Komponen Jaringan

PC

PC atau Personal Computer merupakan perangkat akhir yang digunakan untuk mengirim atau menerima data.

🔀

Switch

Switch menghubungkan beberapa perangkat dalam jaringan lokal dan meneruskan frame berdasarkan MAC address.

🛣️

Backbone

Backbone adalah jalur utama jaringan yang membawa trafik dari berbagai bagian jaringan.

🏢

Distribution

Distribution merupakan lapisan yang menghubungkan Access Layer dengan Core Layer dan dapat menjalankan fungsi routing serta policy tertentu.

⚡

Core

Core merupakan bagian inti jaringan yang menyediakan konektivitas berkecepatan tinggi antarbagian jaringan.

🌐

Router

Router menghubungkan jaringan yang berbeda dan meneruskan paket berdasarkan informasi routing.

Mekanisme Kerja

Bagaimana data bergerak dari satu PC menuju jaringan lain?

1
PC membuat data

Pengguna menjalankan aplikasi dan menghasilkan data, misalnya membuka website atau mengirim file.

2
Data menuju Switch

PC mengirim frame melalui media jaringan menuju switch. Switch melihat alamat MAC tujuan untuk menentukan port yang sesuai.

3
Switch meneruskan frame

Switch meneruskan frame menuju perangkat atau jalur yang sesuai berdasarkan informasi yang dimilikinya.

4
Distribution mengatur antarbagian jaringan

Pada jaringan hierarkis, distribution dapat mengagregasi access switch dan menjalankan fungsi seperti routing antar-VLAN atau penerapan kebijakan jaringan.

5
Core meneruskan trafik

Core menyediakan jalur utama berkecepatan tinggi untuk menghubungkan berbagai bagian jaringan.

6
Router menghubungkan jaringan

Jika tujuan berada pada jaringan berbeda, router menggunakan informasi IP dan tabel routing untuk menentukan jalur berikutnya.

7
Data mencapai tujuan

Paket akhirnya mencapai jaringan tujuan dan diteruskan menuju perangkat yang dituju.

Penjelasan Mekanisme

PC → Switch

PC membentuk data kemudian data diproses oleh stack protokol dan dikirim melalui interface jaringan. Pada Ethernet, data dikirim sebagai frame menuju switch.

Switch → Distribution

Switch access menghubungkan perangkat akhir ke jaringan. Trafik kemudian dapat diteruskan menuju lapisan distribution untuk komunikasi antarsegmen jaringan.

Distribution → Core

Distribution mengagregasi trafik dari beberapa access switch. Core kemudian menyediakan konektivitas utama antarbagian jaringan.

Core → Router

Jika tujuan berada di jaringan lain, trafik dapat diteruskan ke router. Router memeriksa alamat IP tujuan dan memilih next hop berdasarkan routing table.

Ringkasan

Komponen Fungsi Contoh Peran
PC Menghasilkan dan menerima data. End device
Switch Menghubungkan perangkat LAN dan meneruskan frame. Access switch
Distribution Mengagregasi jaringan access dan dapat menjalankan routing/policy. Layer 3 switch
Backbone Jalur utama yang membawa trafik antarbagian jaringan. High-capacity link
Core Menyediakan konektivitas inti antarbagian jaringan. Core switch/router
Router Menghubungkan jaringan berbeda dan meneruskan paket IP. Gateway
